
# Library Tracker

A simple Java console application for managing library books.

## Features

- Add new books.
- List all books.
- Search books by title or author.
- Remove books by ID.
- Save and load books using a JSON file.

## Technologies

- Java 17
- IntelliJ IDEA
- Git and GitHub
- JSON File Storage
